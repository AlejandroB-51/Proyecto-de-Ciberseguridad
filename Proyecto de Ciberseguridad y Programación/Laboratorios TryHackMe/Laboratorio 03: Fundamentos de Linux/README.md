Herramientas Utilizadas: Navegador Web y terminal Linux brindada por la web "TryHackMe"

1.- Resumen de la Actividad: El objetivo de este laboratorio es comprender y usar los comandos básicos dentro de la terminal del sistema operativo Linux

2.- Comandos de Linux
   ls: El comando "ls" nos mostrara una lista de los documentos, carpeta y archivos dentro del directorio en el que el usuario esta
   cd: Este comando nos permite movernos entre carpetas y directorios colocando "cd (nombre del directorio o carpeta)", también nos permite salir del directorio actual si solo se coloca "cd" o "cd .."
   cat: "cat" nos muestra el contenido dentro de un archivo 
   pwd: Ese comando nos dirá el nombre del directorio actual
   whoami: Nos mostrara que usuario somos
   echo: Muestra el texto que se le indica
   find: Nos ayuda a buscar un archivo por su nombre
   grep: Busca texto dentro de un archivo 

3.- Operadores
  &: Al usar ese operador el comando se ejecutara el segundo plano permitiéndonos seguir colocando comandos
  &&: Este operador espera a ejecutar el primer comando para luego ejecutar el segundo
  >: Se utiliza para redirigir la salida de un archivo, esto sobreescribira todo lo que hay en el archivo
  >>: Este hace lo mismo que ">" pero en lugar de sobreescribir simplemente agregara la salida del archivo al final
